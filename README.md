# Blackjack Prediction & Simulation Project

## 🥅 Project Purpose

This project demonstrates how to **tilt the odds in Blackjack in favor of the player** by combining traditional game‐theory strategy with machine‑learning–driven decision making.

* **Rule‑based foundations** — basic strategy charts & Hi‑Lo card‑counting.
* **Supervised learning** — a Random Forest classifier that predicts the optimal action (Hit / Stand / Double) from game state.
* **Interactive simulator** — a Python/Jupyter implementation where the ML agent plays against a standard dealer and dynamically sizes bets based on the running count.

---

## 📊 Data Set

* **Source**  — Kaggle *Blackjack Hands* (link pending; a Google Drive link will be added here).
* **Schema (raw)**  — per‑hand JSON with cards remaining, dealer upcard, player hand, actions taken, running Hi‑Lo count, and win outcome.
* **Pre‑processing** (handled in `blackjack_notebook.ipynb`):

  1. Parse stringified lists with `ast.literal_eval`.
  2. Engineer state features:

     * `player_total` — value of the player hand at decision time.
     * `dealer_card` — numeric value of dealer upcard.
     * `soft` — 1 if the hand contains an Ace counted as 11.
     * `running_count` — Hi‑Lo count when the decision is made.
  3. Extract the first decision in `actions_taken` as the prediction label (`H`, `S`, `D`).
  4. Save the processed DataFrame for reuse.

---

## 🤖 Model Training Pipeline

| Step                    | Description                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------- |
| **1. Label encoding**   | Map `H`, `S`, `D` → `0`, `1`, `2` using `LabelEncoder`.                                           |
| **2. Train/test split** | 80 % train / 20 % test (`train_test_split`, `random_state=42`).                                   |
| **3. Classifier**       | `RandomForestClassifier` (`n_estimators=100`).                                                    |
| **4. Evaluation**       | `classification_report` (accuracy, precision, recall, F1) & confusion matrix.                     |
| **5. Persistence**      | Save model + encoder via `joblib.dump` ( **not checked into Git** because the model is >100 MB ). |

To regenerate the model after cloning:

```bash
python train_model.py          # optional helper script
# or open the Training section of blackjack_notebook.ipynb and run all cells
```

> **Tip 🔍** Add more hands or switch to Reinforcement Learning (DQN, Monte‑Carlo control) for future experimentation.
